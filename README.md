# Northstar Studio — GitHub Pages Demo

A small static website made with HTML, CSS and JavaScript. It is intended as a sample project for practising GitHub Pages deployment.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive layout and styling
- `script.js` — mobile navigation and current footer year

## Run locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code if it is already installed.


## Notes

This is a static website. GitHub Pages can host static HTML, CSS and JavaScript, but it does not run server-side applications or databases.

The contact email is a placeholder (`hello@example.com`). Replace it only if you intend to publish a real public contact address.
